HellRoad is a completely standalone game featuring 32 amazing maps.

The IWAD file is the file used by Doom that contains all game data (graphics, sound effects, music, etc.). HellRoad includes all of these and can be played on engines like UZDoom, GZDoom, and Zandronum, but if you want to play only on ZDoom, you need to change the file extension from IWAD to WAD. Then run it as PWAD.
